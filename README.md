## 📌 Project Overview
This project presents an **assistive smart home system** designed for **visually impaired users**, enabling them to control home appliances using a **Braille-based tactile interface**.

Unlike traditional systems that depend on screens or voice commands, this solution provides a **completely sight-independent interaction model** using **ESP32 and IoT technology**.

---

## 🚀 Key Features
- 🔤 **Braille Input System** (6-button tactile interface)  
- 📡 **Wi-Fi Based Communication (TCP/IP)**  
- 📱 **Blynk IoT Integration for Remote Monitoring**  
- 🔔 **Audio + Vibration Feedback System**  
- 🔥 **Dual-Sensor Fire Detection (MQ-2 + IR Flame)**  
- 🔐 **Password-Protected Door Lock (Servo Motor)**  
- 💡 **Appliance Control (Lights, Fan with Speed Control)**  
- ⚡ **Works even without Internet (AP + STA Mode)**

## 🔄 Working Principle
1. User inputs command via **Braille keypad**  
2. ESP32 converts it into **ASCII command**  
3. Command is sent via **Wi-Fi (TCP protocol)**  
4. Appliance module executes action  
5. Feedback is provided via **buzzer & vibration**  
6. Status is updated on **Blynk App**
